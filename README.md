# Orman Yangını Davranış Analizi ve Simülasyon Motoru

Akdeniz havzası ve Türkiye genelinde; geçmiş yangın kalibrasyonu, Copernicus DEM arazi eğimi, uydu/OSM tabanlı bitki örtüsü ve doğal/yapay engeller ile yangın öncesi son 5 günlük + anlık hava durumu verilerini birleştirerek 0–12 saatlik yangın yayılım simülasyonu üreten hesaplama motoru.
